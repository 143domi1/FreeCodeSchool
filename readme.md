# Freecodeschool

**Freecodeschool** is a completely free and open source **(foss)** platform dedicated to provide **you** (the user) with the **BEST** possible learning experience while you are learning how to code.

## About the platform

**Freecodeschool** is a completely free and open source **(foss)** platform dedicated to provide **you** (the user) with the **BEST** possible learning experience while you are learning how to code.
Why you ask? Well when i (**the original creator of this repo**) started to learn how to code, it sadly wasn't that simple and accessible.
So i decided to start making this platform for future people like us (me and the **user** currently reading this) get the best possible experience no matter what skill level you are.
And a reminder, this platform is **100%** free and will always remain **free**.
<br>
No **ads**. No **subscriptions**. No **selling your data**.
<br>
***FREE*** forever.

## Content
**Freecodeschool** currently contains simple **python** and **generic** coding lessons (as of the platform's start).
Now obviously as the platform gets bigger it will have more content on it.
