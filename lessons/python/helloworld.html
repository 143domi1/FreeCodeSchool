Hello world!

Now finally, what we have all been waiting for. Coding. Let's get started, make a folder on your PC (you can name it anything you want).
You can now (if you used the default install options) open Python idle the same way you open any other program on your PC. Now create a new file
so you can open the editor. Look around for a few minutes, you'll code here for a while.
So now, write this into the editor:
print("Hello world!")
Think about what it means, go ahead once you thought it over.
Now, let me tell you what it means. print() (print() is a function that Python already has, but do not worry about that yet. But that also means, only this (print()) variation of print() works) means
print onto the screen (well it says it in the name, what did you expect.) print() is a function, but that doesn't matter at the moment for us.
After print there MUST go these "()" parentheses (to contain the content that's going to be printed (those are called arguments, but that is not important for now)).
In the arguments part, (the part inside the parentheses). There can go a LOT of things, for example: Variables, Strings, Integers, Characters and some other things, but those which i just listed
are the most important ones (Characters (char) are NOT different to strings in Python, but they are in other languages, so keep that in mind for the future). Look at these few examples:

Variables:
thisIsAVariable="Hello, this is a variable."
print(thisIsAVariable)
Strings:
print("Hello, World!")
Integers:
print(200)
Characters:
print('H')
Now, try writing each one of those into the editor (manualy, not with copy-pasting), change the values to ones you want, play around. See how it works. Don't forget to save and run the program to try them out,
also when naming your filename, be aware that while you can put spaces in the filename sometimes, it is not suggested.
Now, you might wonder what a Variable is? Well, you'll see it in the next lesson.
