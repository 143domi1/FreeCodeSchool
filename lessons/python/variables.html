What are Variables?

Alright, now let's get started. What even ARE Variables? you might be thinking right now.
But do not worry, as they are not a complex topic. In the previous lesson, i told you about the most common few types of variables. Do you remember them?
If no, do not worry, as we are going to be covering them here again. If yes, then you probably have good memory (lucky you).
So, there is a decent lot of types of variables in Python, here are the most basic ones you'll need:

  1. String
  2. Integer
  3. Float
  4. Boolean

Important thing is, no 2 variables can have the same name, if you assign a new value to the same variable, the previous value will get overwritten (but it depends are they local or global).
Strings
Strings are in the simplest sense a sequence of characters. They are most commonly called "str". To define a string you can use double quotes ("") and single qoutes (''). Example:
Double quotes
stringVar="Hello, this is a string with double quotes."

Single quotes
stringVar='Hello, this is a string with single quotes.'
Integers
Integers are numbers, but be careful here, integers are in the set of all integers (ℤ). Which means, they include both negative and positive numbers. BUT they do NOT include
decimal numbers. Examples below:
positiveIntVariable=20
negativeIntVariable=-20
To use decimal numbers, you need to use Floats.
Floats
Floats are ALSO numbers, but a little bit diffrent than integers. They are in the set of all rational numbers (ℚ), which means they include decimal numbers.
Examples below:
positiveFloatVariable=20.06
negativeFloatVariable=-20.06
Booleans
Booleans are a little diffrent than the other types. It can only represent one state at a time. There are 2 options, True (1) or False (0). In Python, we use booleans like this:
trueOrFalseStatement=True
falseOrTrueStatement=False
Like you probably thought already, Booleans represent True or False statements.
