History of programming languages

One of the earliest high level compiled programming languages was made around the 1950s. Developed by Alick Glennie. It is called Autocode.
Now, a lot of programming languages have been made since then to today, but obviously im not going to list them all here. A few of the big ones are:

  1. C - developed around 1969-1973
  2. C++ - developed around the 1980s
  3. Python - developed around 1991
  4. JavaScript - developed around 1995
  5. C# - developed around 2001
  6. Kotlin - developed around 2011
  7. Rust - developed around 2015
But in this course, we are going to be learning Python.

What is Python?

Python is a high level interpreted programming language (now ignore all the words before programming language, they aren't important for now).
It is maintained by the Python Software Foundation. And it was designed by Guido van Rossum. It first appeared on the 20th of February, 1991.
It is considered one of the easiest programming language for beginners by a lot of people, now this varies for everyone (this means for someone it can be VERY hard and for some VERY easy).
