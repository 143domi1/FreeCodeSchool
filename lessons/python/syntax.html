Python Syntax

Python Syntax is very important. Why you say?
For example,
print("Hello, World!")
is NOT the same as:
print "Hello, World!"
While print("Hello, World!") will work, because it contains everything the print function requires.
The print function requires () parentheses.
print "Hello, World!" will NOT work, because it is missing the () parentheses which are a critical part for a function.
